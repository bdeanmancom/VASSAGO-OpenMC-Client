## Vassago 0.2.0 (pre-release)

A free, independent, open-source client for Minecraft: Java Edition-compatible servers.
Not affiliated with, endorsed by, or connected to Mojang Studios or Microsoft. No game code or
assets are included; all art is generated by Vassago.

### Fixed
- **Kick about one second after joining a 26.3 server ("Invalid move player packet received").**
  26.3 servers disconnect clients that send two position packets without a client tick-end packet
  in between. Vassago now ends every client tick the way the official client does.
- Sign-in and login failures are reported accurately. Previously several different Microsoft
  sign-in errors were all shown as "this account does not own the game".
- A Microsoft sign-in that you cancel is really cancelled: it can no longer bring its window back
  later or connect in the background, and nothing from it is stored.
- Cancelling a connection and immediately starting another can no longer revive the first one.
- "Sign in with Microsoft" on a disconnect screen is a choice for that connection only. It no
  longer changes your default profile.
- Taking more than 30 seconds to answer a server's resource-pack question no longer ends the
  connection with a "timed out" message.
- Leaving a server now stops that connection's simulation completely; previously each leave left
  a timer and the loaded world behind until the app was closed.
- `npm start` repairs a missing Electron runtime instead of failing.

### New
- Disconnect screens that explain account problems and offer the next step (sign in, switch
  account, or — for a server you run — how to allow private-server profiles). Whether a server
  wants a verified account is read from the login handshake, so it works whatever language or
  wording the server uses.
- Profiles can be renamed (a whitelist needs the name to match exactly), and the Play page says
  which profile it will join as.
- Servers that translate between versions with ViaVersion/ViaBackwards are labelled, e.g.
  "26.3 · joins as 26.1". When such a server runs a version Vassago speaks itself, Vassago uses
  that version directly instead of going through the translation.
- `npm run check-server -- <host[:port]>` reports whether a server is reachable, which version it
  runs and whether it accepts private-server (offline-mode) profiles.

### Compatibility
| Server | How | Status |
|---|---|---|
| 1.21.4, 1.21.11, 26.1 – 26.1.2 | native | verified by the automated suite |
| 26.3 with ViaVersion + ViaBackwards | client speaks 26.1, server translates | verified by the automated suite |
| 26.2 / 26.3 without ViaBackwards | — | **not supported yet** (the client cannot speak protocols 776 / 777 natively) |
| other 1.20.2 – 26.1 versions | native | experimental, not verified |

**Please read before installing:** these installers are built automatically and are **unsigned**.
The Linux build is launched and tested by the automated suite. The Windows and macOS installers
have been built but **not yet launched or tested** by the project; on macOS the app has so far only
been run from source. Microsoft-account sign-in has had limited real-world testing. See
`DEVELOPMENT_STATUS.md` in the repository for the full list of what is and is not verified.

### Private servers
Private-server (offline-mode) profiles only work on servers whose owner has turned online mode
off. Such servers do not verify who a player is: keep them behind a firewall / IP allow-list or
use a login plugin. Vassago never attempts to bypass authentication on online-mode servers.
